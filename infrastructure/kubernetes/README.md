# infrastructure/kubernetes

Kubernetes manifests for local (kind/Minikube) deployment: Deployments,
ConfigMaps, Secrets, resource requests/limits, liveness/readiness
probes, and labels (`app=edge-device`, `device-id=...`, `fleet-id=...`)
used by the recovery operator to identify and replace workloads.

**Status:** not yet implemented (target: Phase 8).
